# 脱脂牛马 0.3.0 发布说明

`0.3.0` 是一次真正意义上的大版本更新。前几个版本里，「脱脂牛马」主要还是一套团队健身打卡、咖啡记录和战报看板；从这个版本开始，它多了一条完整的游戏化主线：牛马补给站。

这次更新的核心不是给打卡页多塞几个按钮，而是把“每天打开一下、顺手做点轻任务、攒券、抽奖、用道具、看团队动态、再回到健身打卡”这条循环跑通。它让原本偏记录型的工具，开始变成一个带一点经营感、奖励感和团队围观感的小系统。

## 牛马补给站上线

主导航新增了「牛马补给站」。这里是 0.3.0 的主舞台，包含状态总览、补给商店、抽卡池、背包和任务记录几块内容。用户可以在同一个入口里看到自己的银子、抽奖券、背包库存、等级经验、今日任务、近期补给记录和可用道具。

每日轻任务被拆成四个维度：动一动、喝一喝、社交一下、学一点。系统会给每个维度分配一张任务卡，用户完成后可以记录一句状态词。四项任务全部完成后，可以领取 1 张生活券；真实健身打卡也会发放 1 张健身券。任务不是为了制造额外负担，而是把那些“顺手让今天没那么废”的小动作变成可见的进度。

补给站也加入了等级和 EXP。完成每日任务会获得 EXP，真实健身打卡会获得更多 EXP；等级、经验条和称号都会在补给站里展示。这个版本没有做复杂职业、天赋或排行榜，先让成长反馈稳定存在。

## 抽卡、背包和道具开始闭环

抽卡池现在支持单抽和十连。抽奖券来自每日任务、健身打卡和管理员发放的版本福利；十连抽券不够时，可以在确认后用银子补齐，且有每日补券上限。抽奖会产出银子、任务换班券、健身增益道具、弱社交道具和真实福利类奖励。

背包不再只是一个展示区。抽到或购买的道具会进入库存，用户可以在背包里使用。任务换班券可以帮今天的任务换一张；健身增益类道具会在当天打卡时结算额外银子或赛季贡献；弱社交道具可以发起点名喝水、全员起立之类的团队互动；真实福利类道具可以进入兑换流程，等待管理员确认。

为了避免奖励变成一笔糊涂账，0.3.0 也补上了抽奖记录、券流水、经验流水、背包库存、道具使用记录、商店购买记录和真实福利兑换记录。用户看到的是更顺滑的补给站，底下则有一整套可追溯的数据链路。

## 补给商店和真实福利兑换

「补给商店」在这个版本里从静态展示变成了真实购买。用户可以用银子购买可售道具，系统会校验商品是否上架、银子是否足够、是否触发每日或每周限购；购买成功后会扣银子、增加背包库存，并写入购买记录。

真实福利也有了第一版兑换闭环。像咖啡券这类奖励可以从背包发起兑换申请，管理员可以在管理入口确认或取消。确认兑换不会靠口头记账，而是落到系统记录里，方便之后回看。

## 团队动态、周报和企业微信串起来了

0.3.0 把补给站的高价值事件接入了团队动态。稀有抽奖、任务连续完成、强增益打卡、弱社交互动、版本福利等事件，会以团队动态的形式沉淀下来。普通的小动作不会全部刷屏，只有值得被团队看见的瞬间才会进入时间线。

战报中心新增了「牛马补给周报」。它会汇总本周任务、抽奖、道具、兑换、弱社交等补给站数据，管理员可以发布到团队动态，也可以在配置了企业微信 Webhook 后推送到群里。企业微信发送失败不会影响本地发布，未配置 Webhook 时也会自动跳过。

企业微信能力也不只服务周报。这个版本补上了基础发送器、发送日志、高价值事件推送和每日提醒脚本，为后续把关键团队事件带回聊天场景打底。

## 首页主要页面全部做了场景化改造

这次不是只有补给站变了，主应用几个核心页面也整体换了一层视觉语言。

健身打卡页变成了更有现场感的训练场景：团队头部、热力图、活动流和赛季进度都重新整理，打卡反馈更明确。共享看板被改造成办公室便签墙，发布区、便签、公告和装饰素材更贴近“大家一起贴纸条”的感觉。续命咖啡页改成收银小票式计数器，咖啡杯数、今日记录和活动流更像轻松的生活账单。

牛马日历换成桌面月历视图，能同时回看健身和咖啡节奏。战报中心也从普通数据卡片升级成编辑桌面风格，咖啡战报、团队趋势、里程碑、手动周报和补给周报都被放进更统一的版式里。

这些改造不改变原本的数据语义，但会让每个页面更像一个独立场景：打卡像训练区，看板像公告墙，咖啡像小票，日历像桌面计划本，战报像复盘工作台。

## 管理员能力更完整

管理员现在可以处理更多真实运营场景。

首先是全局补卡。普通成员仍然只能补昨天自己的打卡；管理员则可以给同队成员补当前月份、今天之前的漏卡日期。管理员补卡固定奖励 10 银子，计入赛季格子和赛季收入，但不会补发健身券、EXP、boost 或连签阶梯奖励。它用于处理线下确认过的漏打卡，不把补卡变成随意改账。

其次是版本福利。大版本上线后，管理员可以给当前团队全员发放固定 20 张抽奖券，并写入团队动态通知。每个福利批次有独立标识，避免同一批次重复发放。

管理中心也新增了游戏化运营观察能力，包括经济、抽奖、兑换、弱社交、企业微信发送等健康指标，以及只读的配置总览。它们不是编辑后台，不允许直接改奖池或任务卡，但能让管理员在发布和运营时看清当前规则与数据状态。

## 文档、规则和概率更透明

文档中心新增了牛马补给站规则内容。任务、抽奖、背包、道具、兑换、弱社交、周报等玩法不再只藏在代码或口头说明里，用户可以在文档中心看到“这个东西是什么、怎么用、有什么限制”。

抽奖概率也做了公开展示。系统会根据当前奖池结构解释概率口径，避免用户只看到一个抽卡按钮，却不知道奖池里到底有什么、哪些奖励属于银子、道具、社交或真实福利。

## 切换和加载体验更稳

因为补给站和新版页面都加入了大量视觉资源，0.3.0 专门做了一轮主 Tab 性能优化。几个较重的页面被拆成按需加载，导航点击后会立即显示等待态，鼠标悬停和键盘聚焦会提前预加载可能访问的页面。

补给站抽卡池的大图也做了体积优化，重页面首次进入时不再把所有内容一起压进主包。结果是：页面仍然更丰富，但主导航切换的体感比改造前更稳。

## 这次更新的边界

`0.3.0` 仍然是内部试用版本。它把牛马补给站第一条完整闭环放进了生产应用，但还没有做团队目标、排行榜、复杂等级体系、背包扩容、配置编辑后台或自动化周报。

这个版本最重要的验证问题是：补给站会不会真的提高大家每天打开和打卡的动力；轻任务会不会是轻松的顺手动作，而不是新的负担；抽奖、背包和团队动态会不会带来一点可持续的乐趣，而不是很快变成噪音。

如果反馈成立，后续可以继续扩展团队目标、历史周报、更多真实福利、配置发布审计和更精细的运营工具。现在先把 0.3.0 放出来，让这套“健身打卡 + 日常节奏 + 牛马补给”的新形态进团队里跑一跑。
