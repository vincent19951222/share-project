# 今日训练小票静态原型设计

## 背景

用户点击健身打卡 `+` 后，需要进入一个更丰富的确认弹窗。先做独立静态原型页验证信息层级和视觉风格；样式确认后，将同一套小票组件接入真实今日打卡 `+` 流程。

## 目标

- 新增独立路由 `/ui-prototypes/fitness-punch-ticket`。
- 页面呈现“今日训练小票”：训练类型、有氧项目、力量部位、训练时长、肌肉图、取消和确认按钮。
- 控件使用本地状态模拟选中效果。
- 真实健身打卡页面中，当前用户点击今日 `+` 后以全局页面弹窗打开同一套小票组件。
- 小票确认按钮复用原 `handlePunchConfirm()`，提交、错误、日志和刷新逻辑不变。
- 视觉延续项目现有 brutalist 语言：厚黑边、黄色主操作、纸张质感、强阴影。

## 非目标

- 不新增数据库字段、API、真实持久化逻辑。
- 不改变当前健身打卡成功/失败行为。
- 不把补签、管理员补卡、撤销打卡切换到训练小票样式。

## 验收

- 原型路由可打开。
- 真实打卡页今日 `+` 点击后，小票作为 `document.body` 级全局弹窗出现，不被热力图容器裁切。
- 测试能找到标题、主要分组、肌肉图和确认按钮。
- 桌面与移动视口下内容不互相覆盖。
