我说的第二期，核心意思是：**第一期先统一“导航”；第二期再统一“补给站内部页面的骨架和视觉规则”。**

你可以理解成：

**第一期**
用户看到的是：顶部导航终于统一了。  
`牛马补给站` 不再像另一个 app，而是主站里的一个一级栏目。

**第二期**
用户看到的是：补给站里的 5 个页面也终于像同一个系统了。  
`我的状态 / 补给商店 / 任务记录 / 背包 / 抽奖池` 不再各有各的页面壳、各有各的间距、各有各的按钮风格。

具体怎么改：

**1. 三列首页重排**
这是指 `我的状态` 页面。

现在补给站首页有点像“内容都往里堆”：角色、资产、任务、快捷入口、公告、topbar 都在抢位置。

第二期会把首页明确改成一个工作台：

```txt
左列：个人状态 / 赛季进度 / 资产变化
中列：牛马角色 / 等级经验 / 当前效果
右列：今日主线 / 领取补给 / 任务反馈
```

页面上具体变化就是：
- 删除重复的内部 topbar。
- 删除原来的快捷入口 dock，因为二级 tab 已经承担入口。
- 资产不再大面积重复展示，Navbar 右侧已有银子/券/背包。
- 今日任务区域变成稳定右栏。
- 角色主视觉成为中间焦点。
- 首屏更像“补给站控制台”，而不是一串模块。

**2. 商店/背包/任务记录/抽奖池统一页面 chrome**
这里的 `chrome` 不是浏览器 Chrome，而是“页面外壳”：标题区、工具栏、筛选区、内容容器、操作按钮、状态提示这些。

统一后，每个补给站分区都会有同一套结构：

```txt
顶部主导航
二级 tab
页面标题行：当前分区标题 + 关键操作
内容工具栏：筛选 / 排序 / 状态
主体内容：卡片 / 列表 / 机器 / 记录
反馈区：空状态 / loading / error / toast
```

具体到每个页面：

`补给商店`
- 商品分类不再像单独页面里的大导航，而是变成内容区 toolbar。
- 商品卡片使用统一边框、按钮、价格 chip。
- “购买”按钮和其它页面的主操作按钮风格一致。

`背包`
- 背包物品卡片和商店商品卡片共享一套卡片语法。
- 使用/赠送/选择对象的表单风格统一。
- 背包数量和 Navbar 资产 chip 对齐，不重复展示一套大资源条。

`任务记录`
- 不再用完全独立的菜单式入口。
- 今日任务、抽奖记录、兑换记录等用内容区 tabs/filter，而不是再造一套导航。
- 记录列表、状态标签、时间信息统一样式。

`抽奖池`
- 抽奖机可以保留强视觉，但周围页面壳统一。
- 单抽/十连按钮用统一 action button。
- 奖励结果、票数、历史记录和其它页面的反馈组件一致。

**3. 把补给站 UI token 合并进全局规范**
这个更偏工程和设计系统。

现在很多补给站样式可能是散落的硬编码，比如：
- `#111827`
- `#fde047`
- `border: 4px solid`
- `box-shadow: 7px 7px 0`
- 不同页面各自写按钮、chip、panel

第二期会把这些沉淀成共享 token 或共享 class：

```css
--ui-ink: #111827;
--ui-yellow: #fde047;
--ui-border-strong: 4px solid var(--ui-ink);
--ui-shadow-brutal: 6px 6px 0 rgba(17, 24, 39, 0.72);
--ui-radius-panel: 1.25rem;
```

页面上体现为：
- 所有补给站面板边框厚度一致。
- 所有按钮按下效果一致。
- 所有 chip 高度、圆角、字体一致。
- 所有卡片间距一致。
- 补给站和主站的 brutalist 风格慢慢合并，而不是两套视觉语言。

所以第二期不是“再做更多炫的东西”，而是做这个：

```txt
第一期：导航统一
第二期：补给站内部页面统一
第三期：全站设计规范统一
```

更直接地说，第一期解决“我在哪”；第二期解决“这些页面是不是同一个产品”。
